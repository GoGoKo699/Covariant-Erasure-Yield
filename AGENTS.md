# Working with this repository

The authoritative science is organized by topic under `science/`; `science/model.md` owns the model and main theorem. Preserve its exact isometric-encoder scope, fixed loss-fraction limit, worst-pattern quantifier, and input-independent accepted-channel convention.

Before changing a result, inspect its proof and attribution. In particular, retain the distinction between approximate complementary-channel decoupling and exact conclusive recovery, between a finite feasible decoder and a finite optimum, and between number conservation and efficient implementation. The random charge-Haar ensemble and generalized probabilistic-correction conditions are inherited ingredients.

Run `python verification/run_all.py` and `python verification/check_structure.py` after relevant changes. Record fresh commands and inspected revisions. Numerical tolerances check finite instances, not universal theorems. Local verification is permitted; GitHub Actions supplies an additional reproducibility check. A failed workflow must be investigated rather than described as a pass.

Use reviewable branches and pull requests, preserve unrelated changes and the existing license, and inspect the actual merged default-branch tree. Do not change visibility, settings, licensing, or create releases as part of an ordinary scientific edit. Keep private editorial judgments, research-process records, personal teaching procedures, and unpublished submission material outside this public repository.
